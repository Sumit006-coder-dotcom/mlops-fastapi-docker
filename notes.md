Interview Questions

Q1. What is Model Deployment?

Model deployment is the process of making a trained Machine Learning model available for real-world applications to generate predictions using new input data.

Q2. What is an API?

An API is an interface that allows two software applications to communicate and exchange data.

Q3. What is REST API?

REST API is an architectural style that uses HTTP methods to enable communication between client and server applications.

Q4. Why is FastAPI used in Machine Learning?

FastAPI is used to expose trained ML models through REST APIs, validate input data, handle prediction requests, and return responses efficiently.

Q5. What is the difference between GET and POST?

GET retrieves information from a server.
POST sends data to a server, commonly to create resources or process input.
